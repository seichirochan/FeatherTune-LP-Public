🤖 AI構成判定の設定（任意・Gemini APIキー）

AIに歌詞の構成（Verse／Chorus等）を意味から判定させたい場合は、ご自身のGemini APIキーを設定してください。設定しなくても「それなりタグ付け」は使えます。

🔑 入力したキーはこのブラウザに一時的に保持されます。リロード（再読み込み）すると消えます（安全のため永続保存はしません）。

⚠️ APIキーの厳重な取り扱いについて
・APIキーは「あなただけのパスワード」です。他人に教えない／SNS・公開リポジトリ・スクリーンショットに貼らないでください。
・このアプリはキーをあなたのブラウザ内だけで使用し、送信先はGoogleのAPIのみです。FeatherTuneのサーバーやスタッフには一切送信・保存されません。
・キーはこのブラウザに一時的に保持され、リロードすると消えます（安全のため永続保存はしません）。共有PCでも使用後は画面を閉じれば残りません。
・使い終わったら「クリア」でいつでも消せます。
・万一の不正利用に備え、Google Cloud側で使用量の上限設定をおすすめします。
📘 Gemini APIキーの取得方法
  1. Google AI Studio（aistudio.google.com）にアクセス
  2. Googleアカウントでログイン
  3. 「Get API key（APIキーを取得）」をクリック
  4. 「Create API key（APIキーを作成）」を選択
  5. 表示されたキーをコピーして、上の入力欄に貼り付け

無料利用枠があります（一定回数まで無料）。最新の料金・利用条件はGoogleの公式ページをご確認ください。
